Aranyak Resort website — PREVIEW BUILD for https://euniversalweb.com/updates/aranyak/

HOW TO UPLOAD
Upload the CONTENTS of this folder into /updates/aranyak/ on euniversalweb.com, so that these exist:
  /updates/aranyak/index.html        (English)
  /updates/aranyak/bn/index.html     (Bengali)
  /updates/aranyak/images/...        (logo and photos)
Keep the folder structure. Then open https://euniversalweb.com/updates/aranyak/ (with the ending slash;
the page adds it itself if someone leaves it off).

THIS BUILD IS NOT INDEXED BY GOOGLE
Every page carries <meta name="robots" content="noindex">, so the preview never shows up in Google
or competes with the resort's real domain. There is no robots.txt or sitemap.xml here, because
those only work at the root of a domain.

GOING LIVE ON THE RESORT'S OWN DOMAIN
Use the production build (made for https://www.resortsaranyak.com). It is indexable, and it has
robots.txt and sitemap.xml for the domain root.
